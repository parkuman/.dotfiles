# Instructions

- When reporting information back to me, be extremely concise and sacrifice grammar for concision.

<never-write-comments>
**NEVER** write comments as prose. Instead, when you feel like you need to write a comment, put in:

```
// TODO: @PARKER-AGENT <short, concise summary of what you want to say>
```

For example:

```
// TODO: @PARKER-AGENT this block causes the lock guard to be dropped early
```

Use the comment syntax of the language at hand (`# TODO: @PARKER-AGENT ...` in Python/shell, etc.). Never edit or delete existing comments written by a human unless asked.
</never-write-comments>
